# S8 brief: Ask about pay (branch s8-ask-about-pay)

## Endpoint K1 `POST /api/ask` (04 §5.8). Needs `ask.use` (HR Admin, HR Viewer, Finance: yes, 04 §4.5)
Body `AskBody` `{ question }`, trimmed, 1–500 chars, else 400. Flow in order:
1. No `ANTHROPIC_API_KEY`: 503 `ASK_UNAVAILABLE`, detail "Ask about pay isn't set up on this server." No log row.
2. Caps: count today's (UTC) `ask_log` rows with outcome `answered|cannot_answer|error`, for this user (30) and everyone (300) (`config.askUserDailyLimit`, `askGlobalDailyLimit`). Over either: write a `rate_limited` row, 429 `ASK_LIMIT_REACHED`, `Retry-After` = seconds to next UTC midnight, detail "You've used your 30 questions for today." or "The demo has reached today's question limit."
3. Interpreter. Timeout, API error, `stop_reason` `refusal`/`max_tokens`, no tool call, or zod parse failure: log `error`, 503 `ASK_UPSTREAM_FAILED`, detail "Couldn't read that question right now. Try again, or rephrase it."
4. `cannot_answer` tool or semantic rule fails: log `cannot_answer`, 200 `kind:"cannot_answer"`.
5. `run_pay_query`: resolve names to IDs, run engine as viewer (Finance min group), render template, log `answered` with query JSON and token counts, 200 `kind:"answer"`.

Answer: `{ kind:"answer", question, answer, interpretedQuery:{metric,groupBy,filters:{countries,departments,jobTitles,levels,genders}}, interpretation:[{label,value}], result:{groupBy, rows:[{key,label,headcount,suppressed,value}]}, fxAsOf, usage:{usedToday,dailyLimit} }`. Example interpretation: Metric "Median salary"; Grouped by "Nothing"; Country "India"; Job title "Software Engineer"; Level "L3 Senior". `none` row: key "all", label "All matching employees".
`value`: headcount `{type:"count",count}`; money metrics `{type:"money",usd:Money,local:Money|null}`; outsideBandCount `{type:"outsideBand",below,above,total}`; genderGap `{type:"gap",comparable,gapPct,women,men,likeForLike}` (not comparable: gapPct, women, men null). Suppressed row: `headcount:null, value:null`.
Cannot-answer: `{ kind:"cannot_answer", question, reason, message, suggestion, examples, usage }`. `message` from template; `suggestion` model text, plain, max 200 chars (truncate); `examples` fixed: "How does total payroll split by country?", "How many people are paid outside their band in the US?", "What is the gender pay gap for Account Executives by level?".
`ask_log(user_id, asked_at, question, outcome, interpreted_query NULL unless answered, input_tokens, output_tokens)` exists; indexes I13, I14. `me.askEnabled` = key set and `ask.use` (exists).

## Interpreter (04 §7, ADR 0008, D-036)
`QueryInterpreter.interpret(question, context) -> {kind:"query",query} | {kind:"cannot_answer",reason,suggestion}`. `AnthropicInterpreter` (SDK client injected): `model: config.ASK_MODEL` (default `claude-haiku-5-5`), `max_tokens:512`, 15 s timeout, `maxRetries:0`; `system` = 04 §7.3 prompt with today; tools `run_pay_query` and `cannot_answer`, both `strict:true`; `tool_choice:{type:"any"}`; one user message, question only. Tool schemas exactly 04 §7.2, built once at startup from reference data: metric enum `headcount,total,average,median,p25,p75,min,max,outsideBandCount,genderGap`; groupBy `none,country,department,jobTitle,level,gender`; filters `countries` (codes), `departments`, `jobTitles` (names), `levels` (codes), `genders` (codes), all required, `additionalProperties:false`, no maxItems. `cannot_answer`: `reason` enum `individual,trend,edit,multiple,unsupported,unclear,offTopic`, `suggestion` string. Shared zod `StructuredQuery` mirrors it; arrays capped at reference list size.
After call (§7.4): zod parse, enums case-insensitive → canonical; `genderGap` with `groupBy:"gender"` or non-empty `genders` → `cannot_answer` `unsupported`; resolve names to IDs → `PayFilters`; `aggregatePay([metric] + headcount for money metrics)`.
`FakeInterpreter(Map<question, InterpretResult>)`, unknown → `cannot_answer` `unclear`; option to throw. Map built from `apps/api/evals/ask-eval.json` plus one extra entry hitting a Finance-suppressed group (05 §6.1).
Engine `genderGap` (04 §6 step 3): per 02 §4, 5-and-5 minimum, local currency when single-currency, else USD. Gap `(meanMale-meanFemale)/meanMale*100`, positive = women paid less, `gapPct` from shared `gapPct`.

## Templates (04 §7.6, `modules/ask/answer.ts`, pure)
`{metric phrase}{group phrase} for {scope}: {value}{base}.` Metric: headcount "Headcount", total "Total annual payroll", average "Average salary", median "Median salary", p25 "25th percentile salary", p75 "75th percentile salary", min "Lowest salary", max "Highest salary", outsideBandCount "Employees paid outside their band", genderGap "Gender pay gap". Group: "" or " by country|department|job title|level|gender". Scope: job titles, levels (`L3 Senior`), departments, genders, countries, joined ", "; several values " or "; none "all active employees". Ungrouped money: `INR 20,48,000 (USD 23,552)`, USD only if mixed. Count: number. Outside band `21 (12 below, 9 above)`. Gap `women paid 8.0% less than men` / `more than` if negative / `no measurable gap (0.0%)`, then ` (like-for-like)` or ` (unadjusted: mixes roles and levels; see Pay equity for like-for-like cohorts)`. Grouped: ends with ":". Base: money and outside band `, based on N active employees`; headcount none. Like-for-like: exactly one country, one title, one level, groupBy none. Empty `No active employees match {scope}.` Suppressed `Some figures are hidden to protect groups of fewer than 5 employees.` Gap not comparable `Too few women or men in {scope} to compare (at least 5 of each needed).` FX never in sentence.
Reasons: individual "Ask about pay answers questions about groups, not individual people. Use the employee list to look someone up."; trend "Ask about pay only knows current salaries, not changes over time."; edit "Ask about pay can't change data. Use the employee pages to make changes."; multiple "Ask about pay answers one figure at a time. Try asking for one."; unsupported "Ask about pay covers annual base salary only (no bonuses, equity, tax or net pay)." or, for the gender rule, "The gender gap can't be filtered or grouped by gender."; unclear/offTopic "I couldn't turn that into a pay question. Try one of the examples below."

## Eval (05 §6)
`apps/api/evals/ask-eval.json` `{version:1,cases:[{id,question,expect:{kind:"query",query}|{kind:"cannot_answer",reason},tests}]}`, the 15 cases of 05 §6.3. `npm run eval`: exact match after lower-casing enums and sorting filter arrays; cannot_answer scores reason only; prints a table; writes `docs/evals/ask-eval-YYYY-MM-DD.md` (model, prompt hash, expected, actual, pass/fail, total). Bar 13/15; each failure one line (prompt, schema or expectation wrong). Manual, needs key, never CI.

## Gap rulings for this slice (user delegated, see overrides.md)
1. `interpretation`: Metric (metric phrase), Grouped by ("Nothing", or "Country", "Department", "Job title", "Level", "Gender"), then one row per non-empty filter in order Country, Department, Job title, Level, Gender; values are display names (countries by name, levels as `L3 Senior`, genders by reference name), several joined with " or ".
2. `usage.usedToday` counts the current question (first of the day is 1). Only `answered|cannot_answer|error` count.
3. Gender-rule refusal (`unsupported`): `suggestion` = `What is the gender pay gap for {scope}?` with the genders filter removed and groupBy gender dropped; scope as in the templates.
4. System prompt: 04 §7.3 verbatim, `{{today}}` filled. Changes only through the eval loop (05 §6.4).

## Decisions
D-003 LLM fills a structured query via tool call; interpreted query shown beside answer. D-004 app works without a key; Ask hidden. D-015 aggregate only, one groupBy, no individuals, trends or edits; Finance minimum applies. D-036 haiku, two strict tools, tool_choice any, model sees only question and allowed values, our code writes the answer. D-037 $5 workspace limit, 30/300 per UTC day, 512 tokens, 15 s, no retries, 503 without key. Dependency: `@anthropic-ai/sdk` (ADR 0008), pin exact.
